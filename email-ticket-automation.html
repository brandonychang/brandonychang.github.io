Problem System Impact Next

01 / Problem

The inbox worked.
The workflow did not.

Access issues, broken reports, data questions, and technical requests all entered the same shared inbox.

Ownership and follow-up depended on memory. Leaders had no clear view of volume, aging work, or team capacity.

Access

Get people into the right tools.

Access and permission requests became the largest category.

Data

Find why the number looks wrong.

Analysts traced source data, report logic, and discrepancies.

Support

Keep work moving.

Every request needed an owner, status, and next action.

My role

Keep email simple.
Automate everything behind it.

I built the Outlook extraction pipeline, classification logic, priority rules, deduplication, assignment system, SLA tracking, dashboard, and reminders.

Field teams
Keep using the same inbox.
Analytics team
See every request, owner, priority, and status.
Leadership

02 / System

From inbox
to structured queue.

Before

Email was the system.

  • No shared backlog.
  • Ownership lived in people's heads.
  • Aging requests were hard to see.

After

Every request has a record.

  • Emails captured automatically.
  • Owner, priority, status, and SLA tracked.
  • Dashboard and reminders surface open work.

Workflow

Five steps.
Minimal admin.

  1. 01

    Capture

    Read Outlook and group each conversation.

  2. 02

    Classify

    Identify request type, workstream, and priority.

  3. 03

    Assign

    Add an owner and service deadline.

  4. 04

    Track

    Update status from replies and manual changes.

  5. 05

    Surface

    Refresh the dashboard and send weekly reminders.
