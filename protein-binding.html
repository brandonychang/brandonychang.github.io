Machine learning · Structural biology

Protein Binding Prediction

A structure-informed machine-learning pipeline for predicting protein-ligand binding while protecting model evaluation from data leakage and difficult molecular parsing cases.

Role

Modeling, data engineering, and evaluation

Dataset

967 PDB protein-ligand complexes

Methods

PyTorch, Keras, RDKit, Biopython

(01) — Case study

Reliable modeling starts with reliable data

Build the structural dataset

Parsed protein and ligand structures from 967 PDB complexes and assembled model-ready representations with RDKit and Biopython. The workflow accounted for inconsistent identifiers, missing records, and molecular edge cases.

Evaluate model families

Tested structure and sequence inputs from tools including AlphaFold, OmegaFold, and ESMFold, then trained neural architectures in Keras and PyTorch. A Conv1D model reached a mean absolute error of approximately 4.05 kcal/mol.

Correct leakage

Identified and corrected UniProt-to-PDB leakage that inflated validation performance. Rebuilt the evaluation approach so related structures did not give the model an unfair advantage.

Harden the pipeline

Created more than 100 tests for parsing and structural-data edge cases. The tests made failures visible earlier and improved confidence in the dataset and evaluation results.
