Side project · AI learning platform

ChatDB

A schema-aware SQL and NoSQL learning platform that helps users write queries against a real database structure, run them safely, and learn from execution feedback.

Role

Product vision, PRDs, and prototype direction

Product

Interactive query-learning environment

Methods

SQL, NoSQL, schema retrieval, guardrails

(01) — Case study

Learning through safe execution

Define the learning problem

Static tutorials teach syntax without the relationships, naming conventions, and constraints of a real database. ChatDB reframed the experience around a user's active schema and the query they were trying to construct.

Make the schema visible to AI

Specified automatic extraction of tables, columns, data types, and relationships so query guidance stayed grounded in the available database structure instead of inventing tables or fields.

Generate useful query guidance

Designed a flow that retrieves the relevant schema context, combines it with the user's request, and produces suggestions aligned with the correct tables and relationships.

Protect live execution

Defined guardrails for unsafe operations, timeouts, sandboxed data, and read-only query paths. Users could test and correct real queries without risking destructive database changes.

Measure learning

Authored success metrics around execution rate, query correctness, construct coverage, and correction behavior. The live-query prototype compared hands-on feedback with static examples and generic LLM suggestions.
