HSG Analytics · Operations platform

Email-to-Ticket Automation

A lightweight platform that converts a shared Outlook mailbox into a structured, self-updating ticket system without asking field teams to change how they submit requests.

Role

Architecture, development, and roadmap

Scale

Approximately 250 records across 40+ fields

Methods

Python, Outlook COM/MAPI, Excel, HTML, JavaScript

(01) — Case study

One controlled workflow

Automated intake

Read the shared mailbox through Outlook COM/MAPI and transformed unstructured emails into structured request records. The process eliminated manual triage while preserving the familiar email submission workflow.

Classification and integrity

Built tiered keyword classification and weighted scoring for request type, priority, business impact, action team, and owner. Idempotent merges preserved human overrides, while conversation-ID and message-ID logic collapsed email threads into one self-updating row.

SLA lifecycle

Implemented business-day due dates with WORKDAY, aging, and live On Track, At Risk, and Overdue statuses. Sent Items matching timestamps resolutions and advances ticket state automatically.

Leadership measurement

Designed an SLA Health Score across adherence, resolution rate, and critical-resolution rate. A Controllable By classifier separated enterprise-IT-blocked work from team-controlled performance.

Offline dashboard

Built a dependency-free HTML and JavaScript dashboard that analyzes backlog, aging, ownership concentration, and intake-versus-resolution trends entirely in the browser with no data upload.

Production roadmap

Defined a two-stage path from the Excel and Python prototype to a SharePoint List with HTML and Tableau, then aligned leaders through proposal decks and demos.
