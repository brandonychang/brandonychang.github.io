Side project · Real-time computer vision

Dog Poop Detector

A real-time behavior-detection product concept that distinguishes a specific dog posture from ordinary movement, records an evidence clip, and sends a mobile alert.

Role

End-to-end product definition

Status

Requirements and prototype workflow

Methods

Pose estimation, event logic, video capture, alerts

(01) — Case study

Turn detection into a useful event

Start with the user problem

Defined the product around a concrete need: identify when a dog completed a specific behavior near a home, preserve evidence, and notify the user quickly enough to respond.

Specify the behavior

Translated the event into observable signals such as body posture, rear and front keypoint relationships, and sustained duration. This separated the target behavior from sitting, stretching, walking, or digging.

Design the event pipeline

Mapped the flow from continuous camera input to pose detection, state-based event confirmation, short video capture, cloud storage, and a phone notification with a thumbnail and link.

Balance model tradeoffs

Compared lighter pose-estimation approaches with heavier action-recognition models. The product requirements prioritized real-time latency and manageable false alarms while preserving enough accuracy for a useful notification.

Define success and iteration

Set success measures for precision, recall, latency, and false-positive rate. Error analysis across lighting, dog size, occlusion, and similar poses provided the roadmap for improving the prototype.
